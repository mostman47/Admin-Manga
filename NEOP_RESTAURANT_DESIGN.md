**Project:** "The story of Com Nha"  
**Source:** [Figma Design File](https://www.figma.com/design/gJZXhlekYNuYdoIaHVuiMi/NeoP-%7C-Restaurant-Food?node-id=434-14460&m=dev)

## 📋 Overview

This comprehensive design documentation covers **"The story of Com Nha"** - a restaurant landing page featuring Vietnamese home-cooked cuisine. The design emphasizes cozy ambiance, authentic recipes, and a modern yet traditional aesthetic through mixed typography, warm colors, and artistic photography framing.

**Canvas Dimensions:** 1728x9637px (Full page flow)

**Structure:**
- Gradient text heading

### 2. Dish Card Component
**Props:**
- `title: string` - Dish name

- `position: {top, left}` - Positioning
- `rotation: number` - Slight tilt

**Variants:**

- Shadow variations

### 3. Image Frame Component
**Props:**
- `image: url` - Food/ambiance photo
- `frameStyle: string` - Border type (painted, plain)
- `maskShape: 'circle' | 'rounded' | 'custom'` - Image mask

**Effects:**
- Artistic frame border (maroon/brown)
- Image rotation (-1°)
- Subtle blur
- Shadow depth

---

### 4. Menu CTA Component
**Props:**
- `label: string` - "MENU" or "Details"
- `icon: 'arrow' | 'chevron'` - Icon type
- `onClick: function` - Click handler

**Styling:**
- Text texture/brush stroke background
- Bold typography
- Arrow indicator icon

## 💻 Implementation Approach

### Technology Notes
- Custom fonts: DFVN Guardilostra, Grape Nuts
- Gradient text requires CSS `background-clip: text`
- Mask effects use CSS `mask-image` or SVG masks
- Layout follows CSS Grid or positioned absolute pattern

### Asset Management
1. Store food photographs as optimized images (WebP, JPEG)
2. SVG files for decorative vectors
3. Texture/paint brush stroke as background-image or PNG
4. Import custom fonts (ensure proper licensing)
